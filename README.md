# Studio Bellecour

Proposition de site vitrine mobile en HTML/CSS/JavaScript, sans dépendance ni compilation.

## Aperçu local

Depuis ce dossier : `python3 -m http.server 8765 --bind 127.0.0.1` puis ouvrir `http://127.0.0.1:8765/`. Ce lien fonctionne uniquement sur l’ordinateur qui sert le site.

## Version de présentation

Palette ivoire, encre et bordeaux ; photo d’accueil dans une arche ; trois réalisations avec liens vers leurs vidéos Instagram ; portrait de Murat ; photos du salon ; avis Planity ; 29 prestations dans huit catégories dépliables ; réservation Planity, téléphone et itinéraire. Menu et barre de réservation adaptés au mobile. Le bloc avant/après a été retiré pour alléger la page ; ses images sources restent disponibles dans les assets.

Aucun lecteur vidéo intégré, formulaire, traceur, bibliothèque JavaScript ou police distante. Les réservations se font sur Planity. Les montants, durées et types de prix ont été comparés à sa fiche publique ; voir AUDIT-TARIFS.json. La validation visuelle et les gestes réels sur téléphone restent à effectuer.

## Avant présentation et publication

Avant présentation : contrôler la page sur téléphone et ordinateur, tester les liens dans les applications du téléphone et définir une offre commerciale précise. Avant publication officielle : faire valider par Murat les prestations, photos et autorisations d’utilisation, texte de présentation, coordonnées et informations d’éditeur ; choisir domaine et hébergement, finaliser les mentions légales et activer l’indexation. Aucun résultat commercial n’est garanti. L’aperçu est non officiel et n’a pas été publié ; noindex et robots.txt ne constituent pas une protection d’accès.
